Place your licensed media here. Set its path in src/content.mjs, for example:
hero: { src: '/media/hero.webp', video: '/media/hero.mp4', alt: 'Your descriptive alt text' }

Use WebP/AVIF images. Recommended: hero 1920×1080; program images 960×720.
Video is optional; include a poster image. Keep videos muted, short and compressed.
The layout reserves media dimensions to prevent jumping while files load.

No source-site imagery is included. Wordmark and client logo areas are placeholders.
